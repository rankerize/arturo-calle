# Arturo Calle — Diagnóstico SEO Integral y Hoja de Ruta

Repositorio de trabajo para el diagnóstico SEO, benchmarking competitivo, auditoría técnica VTEX, preparación para IA (AI-Readiness) y hoja de ruta estratégica para **Arturo Calle** (`arturocalle.com`).

---

## 📂 Contenido del Repositorio

- **`Diagnóstico SEO — Arturo Calle.html`**: Presentación ejecutiva e interactiva de diapositivas con el diagnóstico completo, métricas de GSC, Semrush, auditoría técnica, benchmarking y plan de 12 semanas.
- **`Competidores/`**: Datos históricos y tendencias de competidores (Vélez, Koaj, SevenSeven, Tennis, Chevignon, Ela, Esprit).
- **`Datos keyword planner/`**: Exportación y análisis de volumen de búsquedas del mercado de moda en Colombia.
